# Walmart Black Friday Consumer Purchase Behavior Analysis

## Project Type
Independent Case Study

## Tech Stack
Python, Pandas, NumPy, Seaborn, Matplotlib, Inferential Statistics

## Project Overview
This project analyzes Walmart Black Friday retail transaction data to uncover customer purchasing behavior, demographic trends, and revenue-driving customer segments using Python and statistical analysis techniques.

## Key Features
- Processed and analyzed 550K+ retail records using Python (Pandas/NumPy) for data cleaning, handling missing values, and feature engineering.
- Performed Exploratory Data Analysis (EDA) and built visualizations to identify purchasing trends and transaction outliers.
- Conducted demographic and cohort analysis to identify high-revenue customer segments for targeted Black Friday marketing strategies.
- Applied Central Limit Theorem (CLT) and Z-score methodology to construct 95% Confidence Intervals for validating customer spending behavior patterns.

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Statistical Techniques
- Central Limit Theorem (CLT)
- Z-score Analysis
- Confidence Interval Estimation

## Business Insights
- Identified top spending customer categories.
- Analyzed gender and age-based purchasing behavior.
- Helped derive insights for targeted marketing campaigns and revenue optimization.
